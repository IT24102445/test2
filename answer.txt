The failed-attempt counter is stored in a local stack variable `failed_auth_attempts` inside the `handle_client()` worker thread function, ensuring each connected TCP client maintains its own isolated counter. The agent server uses a multi-threaded architecture where each client connection is handled independently in its own detached POSIX thread (`pthread_create` with `pthread_detach`). When a client exceeds the maximum allowed attempts (3), the server responds with `ERR 006 TOO_MANY_ATTEMPTS`, logs a `WARNING` entry, and breaks from the command loop to close only that specific client's socket descriptor (`client_fd`). Because socket descriptors and thread contexts are entirely private to each connection thread, terminating one connection has zero effect on other concurrently connected clients, which continue normal operation.
